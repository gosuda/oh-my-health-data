# 공식 창구와 접수

접수를 지원할 때 읽는다. 아래 진입 주소는 2026-10-09 확인 기준이며, 실행 시 공식 화면의 기관명·업무·현재 안내를 다시 확인한다.
문서나 스킬을 작성하는 것만으로 실제 민원·청구를 제출하지 않는다.

## 세 가지 경로

| 요청 | 공식 진입점 | 문안의 초점 |
| --- | --- | --- |
| 정보공개청구 | [정보공개포털 청구서 작성](https://www.open.go.kr/rqestMlrd/rqestReg/rqestRegWritingForm.do) | 기관이 이미 보유·관리하는 컬럼 정의서, 제공 승인·계약 문서, 기록관리기준표, 파기 결과 등 특정 문서의 공개 |
| 본인 개인정보 열람등요구 | [개인정보 포털](https://www.privacy.go.kr/front/wcp/dcl/per/persnalInfoAgree.do) | 본인 자료의 열람·정정 및 삭제·처리정지 요청. 대상 파일과 원하는 조치를 구체적으로 지정 |
| 정책·법령 질의 및 개선 요구 | [국민신문고 민원신청](https://www.epeople.go.kr/nep/pttn/gnrlPttn/pttnSmlrCaseList.npaid) | 적용 법령과 보존기준의 설명, 장래 연구 활용 제외 요청의 자율 수용 여부, 선택권 제도 개선 |

정보공개청구에서 새 분석이나 법률 해석을 작성해 달라는 요구는 질의민원으로 분리한다. 보유하지 않은 문서를 있다고 가정하지 않는다.
개인정보 요구가 반드시 인용되거나 원본·가명정보·학습모델이 모두 삭제된다고 약속하지 않는다. 대상별 권리와 제한 사유는 기관 답변으로 확인한다.
일반 공개문서는 병무청 등 실제 보유기관에, 본인 수검자 파일은 해당 파일 운용기관에 요청한다. 다른 기관 보유문서를 병무청 보유로 단정하지 않는다.

## 접수 전 준비

- 현재 화면의 메뉴·입력란·안내를 관찰해 이동한다. 고정 선택자나 과거 화면 순서로 제출 버튼까지 실행하지 않는다.
- 제출물에는 수신기관, 요청 유형, 제목, 질문 ID별 본문, 첨부파일 목록과 공개·회신 방식을 명시한다.
- 사용자가 같은 수신처·내용·범위의 제출을 이미 명시적으로 지시했다면 그 승인을 유지하며 반복해서 허락을 구하지 않는다.
- 전송 승인이 없다면 먼저 검토 가능한 최종 문안과 첨부물을 완성한다. 수신기관·전송 본문·첨부를 보여주고 실제 접수 승인을 한 번 요청한다.
- 승인 후 수신기관이나 개인정보 공개 범위가 실질적으로 바뀌면 변경점만 확인한다. 단순 화면 전환은 새 승인 사유가 아니다.
- 성명·주민등록번호 등 본인정보와 인증정보는 사용자가 필요한 공식 입력란에 직접 입력한다. 초안에는 자리표시자를 쓴다.
- 본인확인·최종 인증·CAPTCHA는 사용자가 공식 화면에서 처리한다. 비밀번호·인증코드·토큰을 대화나 첨부물에 복사하지 않는다.
- 수수료 납부나 비용 발생 선택은 사용자에게 맡긴다. 기술적 차단이나 인증을 우회하지 않는다.

## 상태와 중복 접수 방지

| 상태 | 기록할 증거 |
| --- | --- |
| `draft` | 조사·문안 작성 중이며 전송하지 않음 |
| `prepared` | 검토할 수신처·최종 문안·첨부가 준비됨. 전송 승인 여부를 별도 기록 |
| `needs-auth` | 공식 화면에서 사용자 본인확인·인증 등이 필요함 |
| `submission-uncertain` | 전송 동작 후 완료 여부를 확인할 수 없음 |
| `submitted` | 접수증 또는 공식 신청내역의 접수번호·기관·제목으로 실제 접수 확인 |

버튼 클릭이나 성공처럼 보이는 로딩만으로 `submitted`라고 보고하지 않는다.
전송 직후 네트워크 오류가 나면 같은 요청을 다시 제출하지 않는다. 접근 가능한 공식 신청내역을 한 번 확인한다.
일치하는 접수증이 없거나 확인이 불가능하면 `submission-uncertain`으로 보고하고, 누른 동작과 확인 결과를 남긴다. 중복 여부가 풀리기 전 재접수하지 않는다.
접수 확인 후에는 접수번호, 수신기관, 제목, 공식 화면의 접수일·처리기한과 제출본을 사용자에게 전달한다. 불필요한 본인정보는 가린다.
자동 재조회·정기 추적·후속 제출은 사용자가 요청했을 때만 수행한다.

## 확인할 공식 안내

- [정보공개 절차](https://www.open.go.kr/infOthbc/infOthbc/infOthbc.do), [개인정보 열람등요구 안내](https://www.privacy.go.kr/front/contents/cntntsView.do?contsNo=41), [국민신문고 민원소개](https://www.epeople.go.kr/nep/pttn/gnrlPttn/pttnNtrcnContent.npaid).
- [병무청 처리방침](https://www.mma.go.kr/contents.do?mc=usr0000283)의 자동수집 제한은 ‘정보주체의 사전 허락 없이’라는 조건을 포함한다. 본인 허락이 있는 모든 자동화를 일괄 금지한다고 설명하지 않는다.
- [국민신문고 처리방침](https://www.epeople.go.kr/nep/gdnc/PlHndPlc.npaid)은 대리인의 자동화된 본인전송요구에 사전협의 방식을 안내한다. 단발 민원 입력과 본인전송요구를 구분하고 현재 적용 안내를 확인한다.
- 회신을 받았다면 [회신 대조 및 후속 문안](replies.md)을 읽는다.
