# 병무청 건강정보 근거 지도

`source_baseline: 2026-10-09` — 아래 내용은 당시 확인한 공개자료의 스냅샷이다. 민원·청구 최종안에 사용할 사실이나 법적 설명은 관련 공식 원문에서 현행 내용과 시행일을 확인하고, 확인일을 기록한다. 질문과 관계없는 자료까지 전부 재조사할 필요는 없다. 원문에 접근하지 못하면 과거 확인사항으로 표시하고 현재도 같다고 단정하지 않는다.

## 데이터셋과 수량을 섞지 않기

- 방침의 한국보건의료정보원 제공분은 기본 8열 × 2,820,977행, 검사결과 45열 × 2,745,820행이다. 2025년 발표는 55항목, 기준일 HCDL 카탈로그는 8+48=56항목이다. 차이의 원인은 미확인이며 관리항목 포함 여부나 변경 시점을 추정해 채우지 않는다.
- 현재 카탈로그는 신청 가능한 변수의 설명이다. 이를 2025년 특정 제공 건의 확정 스키마나 과거 모든 검사연도의 제공명세로 소급하지 않는다. 같은 날짜 범위여도 버전·대상·추출 조건을 확인한다.
- 행 수는 고유 인원수가 아니다. 두 표의 인원을 합산하지 않는다. 영상 1,014장은 507명과 구분한다. Kdata 검사자료 3,913,394건은 중복을 허용한다고 설명한다.
- 현재 MMA_BYPJ 48개에는 `BR_CD`(부령코드), `BR_JH`(부령조항과)가 있고 후자의 예시에 정신건강의학과가 나온다. 카탈로그에는 해독용 코드북이 없어 병명·등급 매핑은 미확인이다. HIV·매독이라는 필드는 이 48개 목록에서 확인되지 않았다.
- 과거 46개 컬럼의 HIV, 별도 Kdata 검사자료의 매독, 현재 HCDL의 부령 관련 변수는 서로 다른 근거다. 컬럼 존재는 특정인의 값이 포함되거나 실제 연구기관에 전달되었다는 증거가 아니다.
- `MMA_016`은 HCDL과 별도 자료다. 컬럼은 연번, 부령코드, 부령조항, 질병명, 연령대, 시도, 3~7급이다. 공개 샘플은 일부 마스킹되어 있으며, 전체 자료의 개인·집계 단위나 실제 승인·전송 이력은 확인되지 않았다. 15,994명을 뜻한다고 쓰지 않는다.
- 카탈로그·샘플 공개, 안심구역에서의 원천자료 이용, 연구 승인, 실제 제공·반출은 각각 다른 단계다. ‘전체공개’라는 카탈로그 표시를 개인별 원본의 인터넷 공개로 바꾸지 않는다.

## 보유기간과 권리의 범위

| 자료 층위 | 기준일의 공개 근거와 남은 확인사항 |
| --- | --- |
| 수검자 개인정보파일 | 확인한 지방청 등록은 영구. 모든 검사값·영상·문서 사본이 영구라는 뜻은 아니다. |
| 정상자 흉부촬영 영상 | 검사 규정 제23조 제10항에 1년. 기산점·예외·실제 폐기 이행과 백업은 별도 확인한다. |
| 그 밖의 자체·외부 의료영상 | 같은 조에 10년. 보관 후 다음연도 1월 30일까지 관련 기록물 절차에 따른 폐기 규정과 실제 운영을 구분한다. |
| 질병 관련 자료의 문서 묶음 | 제55조 제2항에 10년. 같은 조의 스캔 등록 의무만으로 전산 스캔본까지 같은 날 삭제한다고 단정하지 않는다. |
| 연구용 가명정보 | 방침에 세 사업의 처리 종료일이 2026-12-31로 기재. 원본·사본·백업·결합정보·추가정보·모델·논문 등의 공통 파기일이 아니다. 평발 건의 연장 표시는 종전 종료일·승인내용까지 설명하지 않는다. |

- 제28조의2는 일정 목적의 가명정보 처리를 동의 없이 허용하는 근거이지, 특정 사업의 적법성을 자동 입증하지 않는다. 제28조의7의 권리 특례를 원본 개인정보의 모든 권리가 사라진다는 뜻으로 확대하지 않는다.
- 법적 삭제·처리정지 요구의 적용 여부, 기관이 자율적으로 장래 연구 활용 제외를 받아들이는지, 위법한 처리에 대한 구제는 별개 질문이다. 일반적인 opt-out이나 삭제 성공을 약속하지 않는다.
- 병역법 제11조의2의 제한 대상은 제1항에 따라 취득한 정보·자료이다. 이를 ‘병원 문서 원문 파일만’으로 좁히거나, 모든 자발적 제출자료에 자동 적용한다고 넓히지 않는다. 연구용 파생변수의 출처와 이 조항의 적용 관계를 질의한다.
- 병무청의 스캔 등록 제도는 판정에 참고한 자료 보관 근거다. 모든 병원 방문기록을 자동 수집한다거나 그 스캔본을 연구기관에 제공했다는 증거로 쓰지 않는다.

## 미확인 사항을 문서 요청으로 바꾸기

| 질문 | 요청할 기존 문서·기록 |
| --- | --- |
| 실제 어느 버전의 무엇을 누구에게 제공했나? | 제공 당시·현행 컬럼 정의서와 코드북, 스키마 변경 이력, 제공·이용 협약, 승인·반출 기록, 최종 연구수행기관 목록. |
| MMA_016은 개인 자료인가 집계표인가? | 레코드 단위·등급 컬럼 정의, 추출·가명처리 기준, 실제 이용 기록, 처리방침의 대응 항목. |
| 원본과 사본은 언제 없어지나? | 자료 종류별 기록관리기준표, 보존기간 기산점·연장 근거, 스캔본·백업 적용 기준, 파기 확인 기록. |
| 취득 진료기록에서 연구 변수를 만들었나? | 자료 출처·가공 경로 문서, 제11조의2 적용을 검토한 문서. |
| 연구가 끝나거나 제외를 요청하면 어떻게 되나? | 사본·결합정보·모델·산출물의 보존·반출·파기 기준과 연장 승인, 장래 활용 제외 정책. |

특정인의 포함 여부는 공개 카탈로그로 판정할 수 없다. 기관 문서 공개 요청과 본인 원본정보 열람 요청을 구분하고, 포함 확인을 위해 가명정보의 재식별을 요구하지 않는다.
