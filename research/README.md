# 병무청 건강정보 조사 노트

캠페인의 사실 확인과 민원 작성을 위한 내부 조사 자료입니다.

조사 기준일은 **2026년 10월 9일(한국시간)**입니다. 현재 단계는 근거 정리와 설계이며, 웹서비스·영상·민원 제출 자동화는 아직 구현하지 않았습니다.

## 확인한 사실

| 쟁점 | 확인 결과 | 해석의 범위 |
| --- | --- | --- |
| 연구 제공 | 병무청 처리방침에 의료데이터 결합 연구, 평발 영상 AI 연구, 군 장병 의료이용 분석이 기재됨 | 연구 제공과 해킹·유출은 별개 |
| 제공 규모 | 방침은 기본항목 8열·2,820,977행, 검사결과 45열·2,745,820행을 기재 | 행 수를 고유 인원으로 바꾸거나 두 표를 합산하지 않음 |
| 항목 수 차이 | 방침은 8+45, 2025년 복지부 발표는 55항목, 현재 HCDL 카탈로그는 8+48 | 버전·산정 기준 차이의 원인은 기관 확인 필요 |
| 현재 검사결과 항목 | 혈액·소변·간염 등 검사값, 부령코드와 부령조항과 항목 확인 | 현 카탈로그에 HIV·매독이라는 필드는 없음. 코드에서 병명·등급이 어떻게 드러나는지는 미확인 |
| 별도 정신건강 자료 | K-data MMA_016에 질병명·연령대·시도·등급 등 11열의 정신건강의학과 부령별 처분현황 등록 | 2023년 자료 15,994건이라는 설명. 개인·집계 단위와 실제 이용 이력은 미확인. HCDL과 별개 |
| 평발 영상 | 507명의 영상 1,014장. 2022년 1월~2024년 6월 범위에서 추출 | 이름·병적번호 대체 및 안심구역 내 분석 조건이 명시됨. 인터넷 전체 공개 영상이 아님 |
| 수검자 파일 보유기간 등록 | 서울·대전충남·전북의 수검자 파일 공개등록에 보유기간 ‘영구’ | 등록 갱신일 미표시. 모든 검사수치·스캔·영상이 영구라는 뜻은 아님 |
| 의료영상 | 현행 규정 제23조⑩: 정상 흉부영상 1년, 그 밖의 의료영상 10년 | 기간 후 기록물 폐기 절차가 규정됨. 실제 개별 삭제 이행은 별도 확인 필요 |
| 판정서류 | 제55조: 판정자료 스캔 등록, 질병 관련 자료 묶음 10년 보관 | 전산 스캔본·백업의 삭제 방식과 기산점은 별도 확인 필요 |
| 가명정보 권리 | 개인정보 보호법 제28조의2는 요건을 충족한 연구 등의 무동의 처리를 허용하고, 제28조의7은 열람·정정삭제·처리정지 등의 적용을 제외 | 원본 개인정보까지 모든 권리가 사라지거나 위법 처리가 허용되는 것은 아님 |

현재 두 테이블의 8+48열 원문 명세는 [HCDL 스키마](hcdl-schema-2026-10-09.json), 과거 HIV·매독 항목의 서로 다른 출처는 [과거 카탈로그](historical-catalogs-2026-10-09.json)에 있습니다. 두 테이블에는 생년·신장·체중·지방청 등 공통 항목이 있으므로 열 수의 합계를 서로 다른 건강검사 종류 수로 표현하지 않습니다. 카탈로그 숫자와 표는 [증거 화면](evidence/)에도 보존했습니다.

별도 정신건강 자료의 [공식 K-data 메타데이터](https://dsz.kdata.or.kr/member/apply/add/data_detail.do?dataId=MMA_016)는 2025년 6월 26일 등록되었으며, 활용목적으로 2025년 합동 데이터분석·아이디어 공모전을 설명합니다. [정리본](kdata-psychiatry-metadata-2026-10-09.json)에는 컬럼 정의만 보존했습니다. 일부 값이 마스킹된 공개 샘플이 있지만, 실제 제공값의 범위나 외부 병원 진료기록 원문 제공을 입증하는 자료는 아닙니다.

OBS의 2026년 10월 8일 기사와 10월 9일 영상은 7월 593건·8월 827건의 **공격 시도**와 약 2억 4천만 건의 **개인정보 보유**를 보도합니다. 해당 보도는 공격이 성공한 적은 아직 없다고 설명합니다. 공격탐지 통계 원본은 확보하지 않았으므로 ‘OBS 보도’로 귀속하며, 실제 유출이나 발표와 공격 증가 사이의 인과관계를 확정하지 않습니다. [OBS 검증 자료](obs-report-2026-10-09.json), [기사 원문](https://www.obsnews.co.kr/news/articleView.html?idxno=1539944)

## 데이터 사용 원칙

- `research/`에는 개인의 검사결과가 아닌 **공개 메타데이터와 근거**를 저장합니다.
- 주장마다 출처, 확인일, 대상기간, 확실성, 확인하지 못한 범위를 붙입니다.
- 가명정보와 익명정보, 공개 카탈로그와 제한된 원자료 접근, 원본 보유기간과 연구 처리기간을 구분합니다.
- 현재 카탈로그를 2025년 제공 당시의 스키마와 같다고 단정하지 않습니다. 과거 HIV·매독 항목은 해당 과거 데이터셋에만 연결합니다.
- 처리방침의 2026년 12월 31일은 연구용 처리기간 종료일입니다. 원본·백업·모델 가중치의 삭제일로 표현하지 않습니다.
- 검사 연도가 연구 대상기간에 들어가도 개인의 실제 포함 여부는 판정하지 않습니다.

## 기관에 확인할 우선 질문

1. 2025년 제공 당시와 현재의 전체 컬럼 정의서·코드북·스키마 변경 이력, 53·55·56항목의 산정 차이.
2. 각 데이터의 실제 최종 이용기관·연구과제, 승인·반출·결합 범위와 자료 종류별 제공 건수.
3. 영구 등록된 수검자 파일에 남는 항목과 별도 1년·10년 보관 자료의 관계, 스캔본·백업의 보존·파기 기준.
4. 병역법 제11조의2에 따라 취득한 정보가 연구 데이터 생성에 사용되었는지와 그 법적 검토 자료.
5. 연구 종료 후 사본·결합정보·추가정보·백업·모델·파생 결과물별 보존기준, 연장 절차, 파기 확인 문서.
6. 향후 연구 활용 제외 요청의 수용 여부, 원본에 대한 열람·삭제·처리정지 요청이 거절되는 경우의 항목별 근거.
7. K-data MMA_016 등 별도 카탈로그의 개인·집계 단위, 실제 승인·이용 내역과 보존기간, 처리방침 공개항목과의 대응 관계.

구체적인 청구 문안 재료는 [질문 목록](questions.ko.json)에 저장합니다. 정보공개청구에서는 기관이 보유한 문서를 요청하고, 설명·정책 개선 질문은 일반 민원으로 분리합니다.

## 근거를 읽을 때 주의할 점

출처별 확인 방법·법적 근거·보유기간의 범위는 [근거 데이터](evidence.json)에 기록합니다. 영구 보유 등록은 [서울](https://www.privacy.go.kr/wcp/pif/sch/personalInfoFileViewPopup.do?prsnInfoFileId=PIF_000000000429577), [대전충남](https://www.privacy.go.kr/wcp/pif/sch/personalInfoFileViewPopup.do?prsnInfoFileId=PIF_000000000429298), [전북](https://www.privacy.go.kr/wcp/pif/sch/personalInfoFileViewPopup.do?prsnInfoFileId=PIF_000000000429808)에서 확인했습니다.

국가기록원이 2022년 1월 발간한 「2021년 기록관리 기관평가 우수 중점 추진사례」에는 병무청 PACS의 10년 보존과 20년 처분 제약을 합친 운영 사례가 있습니다. 이는 과거 특정 기록관리 사례입니다. 현행 규정의 1년·10년과 자동으로 합치거나 모든 현재 영상의 30년 보유 근거로 사용하지 않습니다. [국가기록원 자료](https://www.archives.go.kr/next/common/downloadBoardFile.do?board_file_seq=2&board_seq=101576)

병역법 제11조의2의 목적 제한은 **동조에 따라 취득한 진료기록 등의 정보**에 관한 것입니다. 원문 파일에만 적용된다고 좁히거나, 모든 외부 제출자료에 같은 조항이 적용된다고 넓히지 않습니다. 연구용 파생 데이터에 미치는 영향은 자료 생성 경위와 법적 검토를 확인해야 합니다. [해당 조문](https://www.law.go.kr/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1000459255)
