# Oh My Health Data

**병무청 신검, 내 기록도 연구에 쓰일까?**

자유 오픈소스 소프트웨어 커뮤니티 **gosuda**에서 제작한 시민 캠페인입니다. 병역판정 건강정보의 연구 활용에 공개와 선택권을 요구합니다.

## 세 가지 요구

1. **누구에게 무엇을 제공했는지 공개하라.**
2. **보존 이유와 삭제 기준을 밝혀라.**
3. **연구 활용에 선택권을 보장하라.**

## 기능

- **캠페인 페이지:** 병무청 건강정보의 활용 현황과 공식 근거를 확인하고, 요구서와 공유 포스터를 만들 수 있습니다.
- **[공개 민원 skill](skills/mma-health-data/SKILL.md):** 누구나 자신의 에이전트에 추가해 민원 문안을 자동으로 준비하고, 받은 답변을 분석할 수 있습니다. 브라우저 도구가 있는 에이전트는 공식 창구 접수 절차도 돕습니다.

## 시작하기

```sh
npm install
npm run dev
```

```sh
npm run check
npm run build
npm run preview
```

### 에이전트로 민원 준비하기

사이트의 **민원 skill 받기**에서 ZIP을 내려받거나, 이 저장소의 `skills/mma-health-data` 폴더를 사용하세요. 압축을 풀고 폴더 전체를 skill을 지원하는 에이전트에 추가한 뒤, 다음과 같이 요청하면 됩니다.

```text
mma-health-data skill을 사용해 병무청에 어떤 건강정보를 연구용으로 제공했고, 얼마나 보관하며, 삭제나 연구 활용 제외를 요청할 수 있는지 묻는 청구서를 준비해 줘.
```

문안 작성과 회신 분석을 자동화하는 공개 skill입니다. 브라우저 도구가 연결되어 있으면 공식 창구의 입력·접수 확인 절차도 지원하며, 본인인증과 제출 내용 확인은 사용자가 진행합니다. 브라우저 도구가 없으면 완성한 문안을 공식 포털에 붙여 넣어 제출할 수 있습니다.

청구서·접수번호·회신은 사용하는 사람의 개인 폴더에 보관합니다. `npm run dev`와 `npm run build`는 배포용 ZIP도 함께 생성합니다.
